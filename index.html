🧹 Limpar containers de teste

Cuidado: estas ações apagam dados deste aparelho. Exporte primeiro um backup JSON na tela Relatório. Esta limpeza não pode ser desfeita.

1. Limpar uma área / quadra

Escolha uma área para remover os containers ativos e as pendências que pertencem a ela. O histórico de movimentos e saídas será mantido.

2. Limpar o pátio inteiro

Apaga todos os containers ativos, todas as pendências e todo o histórico de eventos. Use somente para reiniciar os testes do zero.
